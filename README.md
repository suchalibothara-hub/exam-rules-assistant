# Exam Rules Assistant

A standalone exam rules chatbot prototype. Open index.html in a browser or publish this repository with GitHub Pages.

## Scope

This prototype uses built-in generic responses for common exam questions. It does not connect to an AI model, retrieve official exam policies, or provide user accounts. Verify exam-specific details with the exam authority.

## Publish with GitHub Pages

1. Open repository Settings > Pages.
2. Choose Deploy from a branch.
3. Select main and /(root), then save.
4. Open the Pages URL when deployment completes.
